# 📊 Customer Journey & Conversion Funnel Dashboard (Tableau)

## 🚀 Project Overview

This project presents an **interactive Tableau dashboard** analyzing the complete customer journey from **Visit → Purchase**. It identifies key drop-offs, evaluates conversion performance, and provides actionable business insights to improve customer conversion and revenue.

---

## 🎯 Objectives

* Analyze customer behavior across funnel stages
* Identify major drop-off points
* Evaluate acquisition channel performance
* Understand regional revenue contribution
* Enable data-driven decision making

## 📈 Dashboard Features

### 🔹 Funnel Analysis

Visualizes customer progression across stages:
**Visit → View → Cart → Checkout → Purchase**

* Highlights drop-off at each stage
* Helps identify bottlenecks

---

### 🔹 Drop-off Analysis

* ~97% of users drop before completing purchase
* Indicates major funnel leakage

---

### 🔹 Channel Performance

* Direct channel shows highest conversion
* Google & Instagram underperform

---

### 🔹 Region Analysis

* East & West regions generate highest revenue
* South region contributes least

---

### 🔹 Key Insights

* High drop-off across funnel
* Major loss between **View → Cart stage**
* Strong performance from Direct channel
* Weak performance from paid channels
